# Deployed backend only. Everything here ships to Render.
#
# chromadb was removed at Phase 9. It pulled onnxruntime (80 MB), kubernetes
# (81 MB) and grpc (39 MB) as transitive dependencies, none of which were
# used — embeddings come from Gemini and Chroma ran in-process rather than
# distributed. A clean install of the deploy requirements measured 476 MB
# against Render's 512 MB limit.
#
# Vectors moved to Postgres with pgvector: 30 KB instead of 200 MB, and the
# index stops being ephemeral. Render's filesystem resets on every deploy and
# every cold start, so a Chroma index had to be rebuilt each time.
#
# pandas and the generator's dependencies live in requirements-dev.txt —
# they run locally and never in the API.
